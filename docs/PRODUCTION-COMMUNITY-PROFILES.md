# POURRITURE.ORG — Production community space

This document describes the member/profile part of the production version of POURRITURE.ORG.

## Member profiles

Each visitor receives a persistent anonymous site identity. A member can open their profile and customize it without exposing private account information.

Available profile customization:

- display name
- short biography
- forum signature
- avatar image URL over HTTPS
- profile banner image URL over HTTPS
- GIPHY profile GIF
- old-web profile theme
- compact/profile-first layout

The profile keeps the old forum/imageboard visual language rather than becoming a modern social-media card.

## Safety and moderation

- No arbitrary HTML or JavaScript is accepted in profile fields.
- Text fields have length limits.
- Avatar and banner URLs must use HTTPS.
- Profile GIFs are restricted to GIPHY URLs.
- The avatar status is stored separately so moderation can hold or reject an image before displaying it.
- Moderators/admins remain the only people who can access security/IP information.
- The public profile shows only a limited recent-post history.

## Community production space

The production site is intended to support multiple ordinary members, moderators and administrators with separate capabilities:

- members: post, request boards, maintain their own profile
- moderators: review reports, review held posts, manage threads and users according to permissions
- administrators: manage boards, featured boards, board requests, site settings, moderation and security activity

## Visual direction

The UI stays deliberately compact and dated: Verdana/Arial/Tahoma, 1px borders, pale blue/gray panels, underlined links, dense posts and simple controls. Modern social-media cards, glass effects and oversized rounded controls are avoided.
